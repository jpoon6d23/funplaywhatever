場、波、粒子

Field 同 wave 唔係同一樣嘢嘅兩個名。呢頁由一粒電荷嘅場講起，講到近場同遠場，再講到粒子點解其實係場嘅一下波動。

場係底。波係場嘅變化向外跑。一粒粒子，就係場最細嘅一下波動。

場同波唔係同一樣嘢

場（field）

空間入面每一點都有一個數值同方向，話你知放一粒電荷喺嗰度會受幾大力、向邊個方向推。

靜止電荷：場一直喺度，但冇嘢郁，所以冇波。

波（wave）

場嘅變化向外跑。電荷一郁，附近嘅場先變，呢個變化再以光速一圈圈傳出去。

冇場就冇波；但有場唔一定有波。

用海嚟諗

場 = 個海面，每一點都有個高度。波 = 海面上跑緊嘅浪。冇浪，個海一樣喺度。

水波水面

近場同遠場

常見講法：wave 似 radiation，去到無限遠；field 似 induction，有限遠。呢個分類係真嘅，叫近場同遠場。但兩樣都係場，而且分界唔係「去到幾遠」。

1/r³（靜電式） 1/r²（感應） 1/r（輻射） 兩條軸都係每格 ×10

近場：能量出去又返嚟

每震一下，能量推出去，下半個周期又流返入電荷，好似拉橡筋。淨係郁嚟郁去，冇走到。

除非附近有嘢接住：變壓器第二個線圈、手機叉電線圈、八達通。所以呢類嘢一定要貼近先用到。

遠場：能量一去不返

強度跌 1/r²，但個球面面積升 r²，兩樣抵銷。所以穿過每一個球面嘅總能量都一樣，真係走咗。

所以星光可以飛幾十億年嚟到你眼。

最易撈亂嘅三點

  • 近場唔係「有限遠」。1/r³ 永遠唔會變零，只係跌得快。
  • 真正分別係能量有冇走：近場郁去郁返，遠場一去不返。
  • 遠場（波）同近場都係同一個場，唔係「場 vs 波」兩樣嘢。

同之前講嘅連埋：電子自旋嘅磁場跌 1/r³，就係上面條綠色實線。佢係一粒靜止磁石，所以只有呢種場，冇波。

近場有幾大

分界大約喺 λ÷2π。搖得越快，波長越短，近場就越細。

嘢頻率波長 λ近場 ≈ λ÷2π（每格 ×10）
  • 電網嘅近場有成個英國咁大，所以電線差唔多冇輻射，變壓器純粹靠感應。
  • WiFi 嘅近場得 2 cm。你部 router 唔係同手機講悄悄話，係隔住成間屋大嗌。
  • λ÷2π 係細天線嘅估算。天線比波長大嗰陣，分界要另計。

場 → 粒子：兩層，唔係三層

常見諗法：field → wave → particle（quark）。場喺最底，呢點啱。但波同粒子係同一樣嘢；夸克亦唔係條鏈嘅終點。

質子嘅重量，99% 係場嘅能量

膠子場 + 夸克郁動嘅能量 ≈ 99%

質子 = 兩粒上夸克 + 一粒下夸克。三粒夸克本身嘅質量加埋約 9 MeV，質子成個係 938 MeV，即係大約 1%。其餘 99% 係膠子場同夸克郁動嘅能量，經 E = mc² 變成質量。

MeV 係粒子物理用嘅能量單位。即係話，你身體大部分重量係場入面嘅能量，唔係「粒粒嘢」本身。

限制

  • 呢套叫量子場論（quantum field theory），係人類測試得最準嘅理論：電子嘅磁性，理論同實驗吻合到大約萬億分之一。
  • 重力仲未放得入去。
  • 「場係咪真係世界最底嗰層」係詮釋問題。量子場論係目前最好嘅描述，唔等於最終答案。

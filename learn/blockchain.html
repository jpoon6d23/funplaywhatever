Blockchain 嘅本質：一本冇人擁有嘅數簿

Mining = 收集交易，砌一個 block，好似猜數字（蠻力 + 運氣）。解到嘅人挖到幣，將交易永久、公開咁記低 = chain。

用計算力，而唔係政府，去建立陌生人之間嘅信任，防止 double spending：同一筆錢使兩次。

問題

數碼嘢可以 copy：一個幣，點樣唔使兩次？

傳統答案：搵銀行做中間人，大家信佢本數簿。Blockchain 嘅答案：人人都有同一本數簿，冇中間人。咁就要解決兩樣嘢：邊個有權寫下一頁？點樣防止有人呃？

工具一 · 簽名

Sign 同 Verify：證明係你批准

sk · SECRET KEY

私鑰

得你自己知，好似你嘅印章。一串 256 個 0 同 1。

pk · PUBLIC KEY

公鑰

由私鑰計出嚟，人人都知，好似你印章嘅樣本。

MESSAGE · SIGNATURE

內容同簽名

內容例如「Alice 俾 Bob 1 個幣」。簽名係一串數字，同內容綁死。

工具二 · HASH

SHA-256：一份嘢一個指紋

Hash 將任何內容變成一個固定長度嘅「指紋」（256 個 0/1，寫出嚟係 64 個字）。同一份嘢永遠出同一個指紋；改一個字，成個指紋變晒；有指紋，都倒推唔返原文。自己試：

SHA-256 指紋

試下將「1」改做「2」，或者加多個空格。

工具三 · 挖礦

挖礦 = 估數字，估到指紋前面有幾多個 0

礦工將一堆交易加一個數字（叫 nonce）一齊 hash，要搵到一個 nonce，令個指紋以指定數量嘅 0 開頭。冇技巧，冇捷徑，只可以 0、1、2、3… 咁逐個試：蠻力 + 運氣。每多要一個 0，平均就要試多 16 倍。

工具四 · 串埋

每一頁都寫住上一頁嘅指紋：改舊帳，後面全部斷

每個 block 入面都抄低上一個 block 嘅指紋。你改舊帳，嗰個 block 嘅指紋變咗，下一個 block 抄嘅就對唔上，一路斷落去。自己試：改第一個 block 嘅內容。

想改舊帳，就要由嗰頁開始，重新挖晒後面每一頁，仲要挖得快過全世界其他人。呢個就係「用計算力建立信任」。

點解估唔到，慢慢計

2²⁵⁶：大到冇意義

bit

一個位，得兩個可能：0 或者 1。

256 bit

256 個位排埋一齊。每多一個位，可能性乘 2：2 × 2 × 2 …… 乘 256 次 = 2²⁵⁶。

2²⁵⁶ ≈ 1.16 × 10⁷⁷

即係 1 後面 77 個 0。成個可觀測宇宙大約得 10⁸⁰ 粒原子。

用全網速度去估

每秒 10²¹ 次：10⁷⁷ ÷ 10²¹ = 10⁵⁶ 秒。宇宙年齡大約 4 × 10¹⁷ 秒，即係要估宇宙年齡嘅大約 10³⁸ 倍咁耐。

信任由邊度嚟

大家跟最長嗰條鏈：呃人要快過全世界

如果有兩個版本，大家跟累積計算量最多（最長）嗰條。想呃人，例如將俾咗 Bob 嘅錢改返俾自己，你就要自己開一條支鏈，挖得快過全網其他人加埋。即係要控制超過一半計算力，叫 51% 攻擊。

成本：劍橋大學估計，比特幣挖礦每年用電大約 138 TWh，約全球用電 0.5%（2025 年報告）；2025 年 12 月嘅初步數字升到大約 190 TWh。呢啲電，就係「呃人要燒更多電」嘅保安費。

反駁

你可能想講

「有 blockchain，咪冇得呃？」

回應

條鏈本身好難改。

企唔穩嘅位

人會呃。交易所可以倒閉（2022 年 FTX），私鑰俾人呃咗就冇得追，合約有 bug 會俾人爆。條鏈防到改帳，防唔到人蠢。

「挖礦咪嘥電？」

回應

支持者話：嗰啲電就係保安費。冇呢個成本，呃人就好平。

企唔穩嘅位

批評者話：用電同挪威成個國家差唔多，大部分日常交易根本唔需要咁高嘅保安。以太坊 2022 年已經轉咗唔使挖礦嘅方法（Proof of Stake）。

Blockchain 唔係叫你信人，係叫你信數學同成本：呃你嘅代價，大過呃你嘅好處。

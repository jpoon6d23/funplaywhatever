佛係覺者，唔係權威

Buddha = awarer，not authority。佛唔係嚟命令你，係話俾你知佢見到乜，你自己去睇。

佢講嘅嘢係手指，月要你自己望。婆羅門壟斷咗成個社會，有人想退出，佛教係其中一條出路。

點解會有佛教

婆羅門 dominate，有人想走

婆羅門（祭司）話：只有我哋識拜神，只有我哋讀得經；你出世喺邊一層，就成世喺嗰層。有人受唔住，出家做「沙門」，自己搵答案。佛教係其中一班。

好似大公司壟斷，就有人辭職出嚟自己搞 startup。佛教係其中一間，仲要係撐到今日嗰間。

佛 = 覺者

Awarer，唔係 authority

權威

「信我」

佢講乜就係乜。你唔使睇，靠佢就得。佢一走，你就盲。

覺者

「你自己睇」

佢話俾你知佢見到乜，同埋點樣去睇。睇唔睇到，係你自己嘅事。

《葛拉瑪經》佛叫人唔好因為傳統、經書、老師咁講就信，要自己試過，知道係好先做。

現實 vs 涅槃

現實 = 無常、無我；涅槃 = 常樂我淨

現實：無常、無我，緣起和合。涅槃：常樂我淨，即係恆常、無怖、自在、清淨。

Core

緣起：冇嘢係獨立嘅 → 無我

你個「我」由好多嘢撐住。逐樣拎走，睇下仲淨低乜。

戒 定 慧

三樣嘢，不分

攝心為戒，因戒生定，因定發慧。《楞嚴經》

戒

身

管住你做乜、講乜。身唔亂，心先靜得落嚟。

定

心定

個心唔再周圍跳，先睇得清楚。

慧

真理

睇清楚之後，自然就唔會再做蠢嘢，返去幫個戒。

四聖諦

苦集滅道 → 集苦道滅

講嘅時候，好似睇醫生：先講病徵，再講病因。但因果嘅次序係反轉嘅：先有集，先有苦；先行道，先有滅。

點樣離苦

無明 → 貪 → 嗔 → 苦 → 八正道 → 離苦

無明（痴）即係睇唔清。睇唔清就想要，攞唔到就嬲，嬲完就苦，苦完又繼續睇唔清，轉完一個圈又一個圈。喺苦嗰度睇清楚，先有出口。

慧

正見 · 正思惟

睇得啱，諗得啱。

戒

正語 · 正業 · 正命

講得啱，做得啱，搵食搵得啱。

定

正精進 · 正念 · 正定

肯做，知道自己做緊乜，個心定。

八正道就係戒定慧將八條分返落三格，就係上面嗰三個圓。

愛

愛 = attach = desire

有愛，先有「好」同「壞」。有好壞，就有兩種苦。

佛死咗之後，班徒弟點樣保住啲嘢

嗰陣冇紙冇筆，全部靠背。開會叫「結集」：大家一齊誦，對啱版本。

出錢 → 出去傳

宗教第一次大分裂，唔係拗宇宙真理，係拗下晝食唔食得嘢，同埋袋唔袋得錢。二千幾年後，人類都仲拗緊呢兩樣。

懺悔

壞嘢嘅源頭同出口

往昔所造諸惡業，皆由無始貪瞋癡，從身語意之所生，一切我今皆懺悔。《華嚴經・普賢行願品》

根：貪瞋癡

就係上面嗰個輪迴圈。

門：身、語、意

做出嚟、講出嚟、諗出嚟。

果：惡業

由好耐之前已經開始累積。

懺悔

睇到，認，放低。

冇客觀

觀有主，無主無觀

冇一個「客觀」嘅觀。有觀，就一定有個觀緊嘅人。

因果 · 輪迴

主因 + 助緣 → 果，冇上帝

輪迴 = matter 同 energy 轉換，不生不滅。冇一個最高嘅因（上帝）喺頂度話事。

反駁

你可能想講

「常樂我淨同無我，咪自相矛盾？」

回應

一個講現實：冇一個獨立嘅我。一個講涅槃：唔再被牽住走，所以自在。

企唔穩嘅位

涅槃經用返個「我」字，好多人就當咗有個永恆靈魂，咁就同婆羅門嘅「梵我」好似，兜個圈返返轉頭。

「輪迴 = 能量轉換？」

回應

冇上帝做第一個因，靠因同緣自己轉，不生不滅。

企唔穩嘅位

能量守恆講到嘢唔會消失，冇講到記憶同性格會跟住過去。呢個比喻講得到「不生不滅」，講唔到「下一世係同一個你」。

「念佛上天堂，咪同其他宗教一樣？」

回應

方便 → 包容。唔同人用唔同嘅船。

企唔穩嘅位

佛教嘅「天」仲喺六道輪迴入面。淨土原本係一間好學校，等你喺嗰度繼續修，唔係終點獎品。當咗係獎品，就變返「信我」嗰套。

「唔係權威，點解又有咁多經同規矩？」

回應

經同律係船，唔係岸。用嚟過河，唔係用嚟孭。

企唔穩嘅位

佛死咗一百年，班徒弟已經為規矩分家。有字有規矩，就有人拗邊個版本先算。

佛唔係叫你信佢，係叫你自己睇。

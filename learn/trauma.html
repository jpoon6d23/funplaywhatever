創傷點樣形成，點樣解

三句先講，成頁都係呢三句。

唔係你錯

過去嘅創傷令你同自己斷開。唔係你錯，因為嗰陣你冇得控制。

痛係你嘅朋友

痛係個警報。佢唔響，你唔會知要停。

覺察係你嘅責任

因為而家你有得控制。

形成

一代傳一代

上一代有佢哋嘅創傷，佢哋嘅行為變成你嘅創傷。你童年要嘅嘢得唔到，就生出一個信念；信念再生出一套求生方法。之後每次撳到同一粒掣，你都會用同一個反應。

兩條死路

失敗會痛，成功都會卡住

強迫行動有兩個結果。失敗：證明咗「我唔值得」，羞恥。成功：外面贏咗，入面嗰個信念冇郁過，所以卡住。兩條路，同一個終點。

唔係你一個

差唔多每 3 個大人，就有 2 個

美國疾病控制中心 2011 至 2020 年問咗全國成年人：63.9% 童年至少有一樣「不良經歷」，17.3% 有四樣或以上。

解

重新連接：由呼吸開始

唔使分內外。覺察由呼吸著手，全部都係由呼吸嗰度出嚟。由呼吸，你清楚見到呢個世界嘅三條規則：你控制唔到；生命係不斷交易；同埋只有活在當下，你先真正同自己連接。

一 · 控制唔到

唔控制，原來都 OK

你可以閉氣幾十秒，但停唔到佢；你唔理佢，佢都照行。你唔使強迫自己呼吸。

  • 放開控制
  • 放低 Should「我應該點樣」
  • 唔再強迫自己
  • 平靜
二 · 交易

吸完，一定要呼

冇呼吸，你生存唔到。你同呢個世界係一個交易嘅關係：吸入嚟嘅，唔能夠唔付出去。呢個就係生命嘅 cycle。

  • 攞嘅時候，感恩
  • 俾嘅時候，開心
  • 識接受，識給予
  • 合作 → 社群
三 · 當下

眯埋眼，淨係呼吸

注意力全部返到自己度，你感受到存在嘅本質，聽得到自己，唔再係人哋俾你嘅聲音。

  • 聽到自己
  • 見到真正嘅 Want
  • 用自己嘅慾望行動
  • 快樂

抄人哋想要嘅嘢，即係搶咗人哋嘅嘢俾自己，然後問自己點解唔開心。因為嗰啲嘢係人哋嘅，未必係你想要嘅。

Should 同 Want

解咗創傷，你只係返到 0

Should 係人哋俾你嘅；Want 係你自己想要嘅。放低 Should 只係解除痛，叫 debuff；攞起 Want 先係加分，叫 buff。兩段路，兩種方法。

睇到 Should，然後放低；見到 Want，然後攞起。0 叫平靜，唔叫快樂：開心係另外一段路，要自己行。

反駁

你可能想講

「咁即係怪晒父母？」

回應

正正相反。條鏈話俾你知：佢哋都係由佢哋嘅上一代嚟。問 Why，係為咗明白，唔係為咗定罪。

企唔穩嘅位

明白唔等於要原諒、要親近。有啲人，明白完都係要保持距離。

「創傷會經基因遺傳？」

回應

基因會影響你對壓力有幾敏感。

企唔穩嘅位

「創傷本身經基因傳落去」，喺人類身上證據仲好弱。傳得最清楚嘅，係行為：點湊仔、點鬧人、點樣唔講嘢。

「自己諗通就得？」

回應

輕嘅，覺察加時間，好多人自己行得出嚟。

企唔穩嘅位

重嘅（例如創傷後壓力症），有實證嘅治療，例如針對創傷嘅認知行為治療同 EMDR。搵受過訓練嘅人一齊行，快好多。覺察係你嘅責任，唔代表要自己一個做。

唔係你錯，但係你嘅事。
